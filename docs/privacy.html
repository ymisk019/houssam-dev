Privacy

Yazan dev collects only the information needed for accounts, game discovery, publishing, and moderation. The operator must configure Firebase Authentication and deploy the separate publishing API before these services are active.

Information handled

  • Firebase Authentication processes account credentials and Google identity. The site does not store account passwords.
  • The publishing API stores game metadata, private submissions, moderation reports, user reports, review history, and audit records in a private GitHub repository.
  • Submitted covers, screenshots, and game ZIP files remain in that private repository until review. The API verifies Firebase ID tokens and restricts uploads to the submitting account.
  • If configured, bounded game-source excerpts and metadata are sent to Google Gemini and Groq for AI-assisted review limited to pornographic or sexually explicit content. Human administrators decide whether to publish.
  • Approved games and downloads are served publicly through the API. Players can copy public browser content or download approved files even though the source repository stays private.

Providers and retention

Firebase Authentication, Google, Groq, GitHub, Google Cloud Run, and the hosting provider process data under their own terms. The operator controls configuration and retention. No automated submission-retention or account-deletion job is included.

Private submissions and administrator actions are protected by server-side verification of Firebase ID tokens and the administrator custom claim. Never include API keys, authentication tokens, or private personal data in game uploads.

Requests

You can choose not to create an account or submit a game. Publicly served game files may be copied and cannot be made private simply by removing a listing. For questions or removal requests, contact the maintainer through the official GitHub profile.
