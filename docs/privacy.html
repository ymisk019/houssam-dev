Privacy

Yazan dev is designed to collect only the information needed to provide accounts, game discovery, publishing, and moderation. The operator must configure Firebase and provider accounts before these services are active.

Information handled

  • Firebase Authentication processes account credentials and Google identity. Yazan dev does not store account passwords.
  • Profiles may contain display names and profile image URLs. Firestore stores game metadata, private submissions, moderation reports, favorites, user reports, review history, and publication records.
  • Submitted covers and ZIP files are held in Firebase Storage quarantine while under review.
  • Game metadata, static-analysis findings, and bounded source excerpts are sent to the configured Google Gemini and Groq APIs. Do not include secrets or private personal data in game files.
  • Approved game files, covers, and release archives are copied to the configured public GitHub repository and GitHub Pages / Releases. These published files are public and can be copied or downloaded.
  • Signed-in play events may increment per-game play counters.

Providers and retention

Firebase, Google, Groq, GitHub, and the hosting provider process data under their own terms and privacy policies. The application has no automated quarantine-retention or account-deletion job; the operator must configure retention, deletion, and backups before production.

Private submissions and privileged records are protected by Firebase Security Rules and server-side administrator claims. API keys and tokens must never be included in uploads or moderation excerpts.

Requests

You can choose not to create an account or submit a game. Published game files are public; removing a listing does not make already distributed files private. For data questions or removal requests, contact the maintainer through the official GitHub profile.
