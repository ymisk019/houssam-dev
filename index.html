Frequently asked questions

Are games reviewed before publishing?

Yes. Submissions receive optional AI-assisted review for explicit sexual content and require a human administrator's approval before publication.

Can I publish a game for free?

Yes. Create an account and submit a game from the publishing dashboard.

Are downloads private?

Unapproved files stay in a private GitHub repository. Approved games are served publicly through the publishing API without opening the source repository.
